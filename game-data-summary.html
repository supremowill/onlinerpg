Game Data Summary

Player

Health: Defined by PlayerDefinition.hp

Skills: Q, W, E, R are configurable (cooldowns and multipliers).

Main configuration located in: server/src/data/GameDataTypes.ts

Enemies

Key Enemies Examples:

  • Bombardeiro Insano: Throws bombs and lays a minefield. server/src/game/enemies/Defenders.ts
  • Cão dos Infernos: Scales with player level (e.g., max HP and damage). Found in AdvancedBosses.ts
  • Minos, o Árbitro: Adjusts damage based on player's health (LimboBosses.ts).

Passive Definitions

Passives affect bleeding, poison, and lifesteal. It’s part of EnemyDefinition.

Type Effect Duration Chance
bleed_on_hit Bleeding damage over time Optional 0-1
poison Applies poison Optional 0-1

Game Data Root

The core schema GameData contains player configuration, enemy configurations, and versioning (GameDataLoader.ts).
